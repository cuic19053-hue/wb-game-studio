AI 美术候选，按编号替换与回退

  • 自动试玩：无头 Chrome 驱动，采样分数、生命、fps、脚本错误，产出截图与封面。
  • AI 美术：内置图像生成 / OpenAI / Codex 三通道，自动抠浅色背景并缩放，按编号应用或回退。
  • 版本快照：每次构建自动存档，代码 + 规则 + 美术一起回滚。
  • 横竖屏与中英界面，临时只读局域网分享链接与二维码。
  • 零 npm 运行时依赖，只用 Node 22 标准库与本机浏览器 DevTools 协议。
